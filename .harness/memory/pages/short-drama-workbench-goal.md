# 全流程短剧工作台的产品目标

<!-- compiled -->
产品目标是完整、通用、稳定的短剧制作工作台，贯穿剧本、资产图、分镜、视频、声音、审片和交付。以多部作品和跨集制作检验可控性、自然度与返工量。单条样片用来发现问题并建立回归用例。外部项目的方法按通用价值筛选，再适配现有架构。

扩充画风时，年代、题材与画法的组合可独立选择。用同场景样张验证创作者能辨认出视觉差异，其余名称归为别名或标签。工作台支持自定义画风，每个内置与自定义画风都配有相应的示例图。

自定义画风支持从上传图提取正向、反向提示词，也支持用提示词生成示例图。本机画风库可跨项目复用，各剧保留采用时的图文版本。
