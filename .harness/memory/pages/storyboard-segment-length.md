# 按动作连续性和模型时长分段

<!-- compiled -->
先核对所选模型的单次生成时长上限，段内各镜秒数相加须在上限内。把连续动作、对白和反应留在同一片段，通常用 1–3 镜讲完；在动作收住、人物目的改变或时空转换处再分段。合并时保留资产引用，核对切点两侧的人、物和动作状态。
<!-- /compiled -->

## Timeline

- `2026-11-22` **decision** — 《无忧岛》的生成结果显示，连续分镜放在同一次生成里衔接更稳。后续先定每场戏的自然边界，再根据模型上限划分片段。
