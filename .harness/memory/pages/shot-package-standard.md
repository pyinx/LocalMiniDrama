# 结构化分镜是视频生成的输入标准（镜头包）

<!-- compiled -->
每一镜交给视频模型的输入以结构化分镜（SegmentIR）为准，新项目默认开启，全能与经典模式保留为可选。不另建镜头包数据结构。生成分镜前，先按本集剧本提议场景状态（时段、光线、环境）与换装造型，作者确认后创建；分镜绑定它们时会校验归属，场景状态只用时段光线版本，造型只用适用于本集的。

场景参考分工：绑定了状态图，格局与光线都照它；只有场景母版时，母版只管格局与摆设，光线以文字为准。所以只有母版时，「光线与时段」超长也不省略，改为拦下让作者精简。表演写行为，不写情绪：基调只写光线与时段，说话方式写音量、语速、停顿或伴随动作，情绪词只告警。

重新生成或「转为结构化分镜」都保留有采用片、留档候选或审片记录的镜头；采用、留档、锁定都不改 `updated_at`，所以写入前要在事务里重新核对。

## Timeline

- `2026-11-22` **evidence** — 本地 27 条分镜无一使用结构化分镜；用户说明只是没注意到这个选项，不是效果不好。
- `2026-11-22` **decision** — 用户确认以现有结构化分镜为镜头包标准；状态资产由剧本提议、作者确认后出图；已有项目提供一键转换并保留已采用镜头；一键全流程自动采纳提议。
- `2026-11-23` **decision** — 用户确认状态图在场景图之后补出、只生成文本框架时不出图；画布模式跟随结构化开关。
