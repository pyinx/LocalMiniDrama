# 角色头身分离与视频参考图

<!-- compiled -->
角色的头只生成一次，用来锁定身份，表情中性，不画熬夜、受伤这类一时的状态。身体按造型生成，每套造型一张。交给视频和分镜的参考图是程序拼出的「头 + 当前身体」，每个角色只占一张参考图，所有造型里的脸像素一致。不要让生图模型重画整张头身图，否则每换一套衣服脸都会漂。

拼合图的宽高比控制在 2.4 以内，因为 Seedance 2.0 参考图要求宽高比在 0.4–2.5 之间。造型设了起止集，就在这些集里自动用于生视频和分镜图；结构化分镜没指定造型时同样按集选用，显式指定的造型优先。已有角色保持原样，由作者手动转为头身分离。Seedance 2 和即梦的真人认证只覆盖主图，造型图要另行认证。

- `2026-11-22` **decision** — 用户参照优秀短剧的「头像 + 身体」设定图，选择每个角色拼成一张参考图、已有角色手动转换、认证只保证主造型。
- `2026-11-22` **decision** — 用户确认结构化分镜 `wardrobe_id` 为空时按集选用造型（原含义为用主图），使同一镜的分镜图与视频参考一致。
- `2026-11-22` **evidence** — 火山方舟文档：Seedance 2.0 参考图宽高比 0.4–2.5。初版拼合图约 2.8:1，已改为方形身体图并限制在 2.4 以内。
