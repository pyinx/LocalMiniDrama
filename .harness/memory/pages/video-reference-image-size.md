# 视频生成前检查参考图尺寸

<!-- compiled -->
生成前逐张检查分镜实际引用图的宽和高，裁切图按裁后尺寸核对平台门槛（即梦本次要求两边各至少 300 像素）。尺寸不足时，优先从原图或原帧扩大取景，保留关键特征。替换后重开所有共用片段，确认都已引用合格的新图。
