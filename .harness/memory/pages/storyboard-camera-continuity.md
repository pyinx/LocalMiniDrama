# 短剧分镜的机位与运镜

<!-- compiled -->
为同一场戏先选能交代人物关系和关键动作的主机位。演员在画内走动、递物、停顿和反应，都可以由同一个镜头承担。跨到下一个生成片段时，可以继续沿用上一段末帧的机位、景别和方向。

给每次切镜或运镜一个具体理由，例如看清手机上的字、跟随人物跨过门槛，或在人物决定留下时拉开给观众看海。写清运动从哪个动作或哪句台词开始、落在哪里、何时停稳。镜头数量由场面决定。

连播相邻片段，先静音核对轴线、视线和动作，再开声检查对白、停顿和环境声。若删去一次切换仍能看清动作、读懂情绪，就保留原机位。
