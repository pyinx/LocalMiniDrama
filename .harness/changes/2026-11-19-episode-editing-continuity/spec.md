# 分镜接缝与整集剪辑 · 产品和架构提案

## Intent

作者选好每镜表演后，一键就能得到镜序完整、对白清楚的整集。若动作重复或一句话被切断，可以从整集直接跳到两镜交界处，听原版、试剪，再决定是否采用。本文为独立评审后的修订稿，各阶段的验收均待实施。

## Scope

### 默认行为与可选参数

| 谁在何时决定 | 默认行为 | 可选操作及作用范围 |
|---|---|---|
| 作者第一次播放或交付 | 按采用版本、原镜序和完整源段顺剪。原声、同步、缺镜检查自动生效。正常项目可直接导出，无需模型或逐镜确认。 | 只在想调整的镜号间打开有声循环，切换原版和试剪版。点「采用」才影响成片，点「恢复」只撤回这处改动。 |
| 单镜声源 | 优先兑现该镜明确选择的原声、配音或静音。没有选择时保留原声，无音轨则补等长静音。「生成过配音」与「采用配音」分别记录。 | 每镜可改用已有配音、原声或静音，选择跟随工程。静音只作用于该镜主声。旁白、整集音乐各自按作者的独立选择叠加，缺省关闭。 |

| 单个接缝「上一句说完」 | 默认关闭，声音随画面一起切。 | 上一镜有真实可用的尾音时才提供。作者有声试听后采用，仅作用于这两镜。素材不足时说明原因。 |
| 精细调整 | 播到想保留的位置，设为前镜结束或后镜开始，即可试听。 | 按需展开逐帧调整和可用的尾音长度。有效范围由素材决定，交付帧率、采样换算和转码路径由系统管理。 |

**两个场景决定体验是否成立。** 门前中景中手已经摸到把手，近景又把动作重复一遍：先调后镜入点，找到动作方向与进度相接的一帧。若近景换了持物手且找不到完整动作，回到该镜已有候选。另一个场景是「我没怪你」之后的沉默：可以在“你”之前切到听者脸上，让尾音落在反应镜头里。安静的半秒可能正是这场戏最重要的表演，应允许原样保留。

**建议的依据。** 基础精剪只依赖采用片、可用区间和已有的带时间码审片标记。两边已核实重复的帧可作为试剪点，有发声时码可提示截断对白。仅有剧本文字时由作者试听。接入并行质量链后，才可用它的同场尾帧关系辅助判断。静音、暗场和低运动均保留原样。

## Non-goals

完整多轨工作区、转场商店、全片自动删静音、多 Agent 制片流水线、云端过渡帧合成与剪映工程导出都需要额外的产品入口或运行依赖。它们没有进入本次首版建议。画幅、响度沿用已有诊断；色调、角色或空间明显不连续时，优先提示具体镜号、可替换候选和补拍原因。

## Deferred

尚无用户确认的延期项。

## Decisions

按用户本轮要求，修订稿以自然度、完整性和首次使用门槛为取舍依据，分阶段验收。默认自动组装，涉及表演的剪法由作者试听并采用。保声可独立发布，接缝精剪可独立于并行质量链交付。

## Assumptions

混合帧率精剪的后备输出规格和真实作品试点人数是本稿提出的工程及试点取值。帧率写入导出快照；试点门槛须在观看或计时前登记。后续调整均使用新的修订或试点批次。

## Design

### Options considered

| 路径 | 作者得到什么 | 代价与建议 |
|---|---|---|
| 只修声音，保留当前整段拼接 | 立即解决已复现的丢声 | 可独立先发；动作重复、拖尾和反应镜头仍难处理。 |
| 在现有顺剪上增加接缝试听和少量编辑操作 | 可以在已有素材内找出合适剪点，试听后决定 | 推荐。一个作者入口，一份有效剪辑记录，一条现有导出链；剪法可还原。 |
| 引入全功能编辑器或生成式剪辑 Agent | 可任意编排多轨、增删素材和自动重构整集 | 需要第二套工程模型、媒体映射和桌面打包维护。等出现必须依赖自由多轨、外部协作或全自动创作的明确场景再评估。 |

### Interfaces and data

**1. 逐镜确定声源，再合成整集（R1）。** 分镜保存作者显式选择的主声和所选配音的内容身份。原声与环境声已混在同一轨时，改用独立配音会一起替换该轨，试听直接播放这个结果。有主声的镜头保留其时长和语速，缺音的镜头生成对应区间的静音，全静音工程同样输出覆盖全片的静音轨。旁白和已接入的音乐在主声之后叠加一次。主声已经解析的段落，旧后期和结构化后期都只能消费解析结果。

旧工程没有逐镜选择时，普通导出默认用原声。兼容旧调用的整集「使用配音」开关，开启时只对已关联对白音频的镜头选用配音，其余镜头保留原声。显式逐镜选择优先。只有台词文本不足以表示作者要求配音。选中的配音文件丢失或损坏，草稿注明镜号、临时用原声或静音，正式交付要求修复或重选。配音长过可容纳的区间时保留原语速，提示换配音或调整可用区间，正式交付前解决溢出。采用选择随工程归档，发布快照固定实际声源及内容身份。已有成片继续指向原文件。

**2. 原版与试剪版各有修订，共用一个时间编译器。** 分镜拥有镜序与采用片。集级只保存作者采用的接缝改动和修订号。试听以当前采用版为原版，对其叠加未保存改动产生试剪版。两版按各自修订、同一交付规格计算，均能回到同一源动作位置比较。采用后，正式导出和该版试听使用相同的输入快照及时间映射。撤回本处改动保留其他接缝的有效修改。

源区间用整数刻度和源时基表示，含入点、不含出点。可变帧率按显示时间戳（PTS）选覆盖该时刻的帧，排除出点及以后画面。需要精剪或统一帧率时，优先沿用已保存的交付规格，其次保留所有输入共同的恒定帧率；混合帧率、可变帧率或缺少可靠标记时，本稿拟用 25/1 fps，并将结果写入快照。剪点按累计时间对齐输出帧，再求各镜长度。交界正好半帧时向后取整。空区间、超界、前后两处改动把中间镜压到不足一输出帧时，在试听和保存前提示调回；恰好一输出帧可以保留。全片时码和抽取的短窗口使用同一帧编号。

**3. 后期按事件来源定位（R2）。** 本分支的对白音频随所用声源，旁白字幕随旁白。后续结构化台词字幕随对应对白，字卡和镜内音乐事件随源画面，整集 BGM 固定在集时间上，接缝拼图取裁后切点两边的实际帧。保留区间外的镜内画面事件从成片去除，跨界字幕按其有效发声范围处理。只有计划时码时标明估算，精度验收以带已知时码的素材为准。基础分支沿用现有后期，扩展接口只接收该次修订的时间映射和已选声源。并行方继续拥有结构化渲染。记录可复现的集成提交且 AC9 通过后，才开放相应入口。若载入依赖该能力的工程，列出缺项，阻止缺层的正式导出。

**4. 缺镜、换片与恢复（R3）。** 每个接缝改动绑定左右两个镜头、两侧采用版本和媒体内容身份，涉及声音时还绑定对应声源。草稿遇到损坏的 B 可预览 A、C，但标明缺少 B 和临时跳接，按完整有效源段展示相接的两端；无法在临时 A→C 采用剪法。已有 A→B、B→C 修改留作复核，C→D 等有效边界照常生效。普通建议过期可直接失效。正式发布遇到缺镜、所选声源缺失或已采用的接缝改动待复核，须列出镜号与原因。作者恢复素材后可以重新试听并采用，也可明确撤回过期改动、用完整源段交付。缺镜仍须补齐。

提交剪法与发布均复核输入身份和修订号，迟到的试听或并发导出不能覆盖新修订与之前的正式成片。工程包沿用候选映射保存采用的素材和剪法，导入以内容身份重连新 ID。旧工程无剪法即整段顺剪。空集提示需先添加分镜，单镜可直接播放和交付。

**5. 只在必要时重编码。** 未裁的兼容输入可沿用快速拼接，须核对音视频布局、时基和成片各段声音。帧准裁剪、声音调整或输入规格不兼容时，从采用源解码所选区间并按交付规格编码。画幅沿用项目既有检查。

「上一句说完」仅调整前镜主声的出点，余量上限为可用的真实音频和后镜可承接的时长。已知下一句起点时，尾音最多到该起点。面对混合原声且缺少对白时码，展示实际叠听结果并由作者选择或还原。阶段二的普通剪点即可独立使用，声音延续单独通过 AC8 才开放。

### Reuse

- **本项目**的能力地图已有整集合成、后期和分镜制作页。沿用采用版本、交付快照、候选归档、FFmpeg 定位和既有响度、画幅诊断。新增的接缝修改覆盖源片区间，当前整段拼接接口没有承载这些区间的位置。并行方通过 AC9 后从同一时间表读取事件和画面边界。[能力地图](../../project.md#capability-map) · [采用版本](../../../backend-node/src/services/workbenchTakeService.js) · [归档](../../../backend-node/src/services/workbenchTakeArchive.js)
- **前期分镜和 Skill**沿用 Toonflow 的视线/动作核对、waoowaoo 的进出场状态、即梦短剧的接动作和局部补拍指引。有模型时可将这些规则汇入已有创作指导：建议写明镜号、可复查时间点、具体问题和替代处理。无法从画面确定就交作者判断。已有分镜能承载的事实继续放在那里。
- **最低成本的动作顺序**是保留 → 调剪点或声音 → 换已有候选 → 定点补拍。若换手、越轴或光向突变在整段内都无法通过剪点解释，应直接指出原因和受影响的镜号。创作者决定是否发起新的生成任务。[研究与取舍](evidence.md)
