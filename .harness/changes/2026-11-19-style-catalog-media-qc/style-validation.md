# 画风验证

## 素材与样张

以项目两个入口原有的 39 个值为基线。Toonflow（6086cdff）的 11 条和 video-canvas（f0b8ced3）的 45 条逐条归入共享目录 `backend-node/src/constants/styleCatalog.json` 的 sources。一个源条目只出现一次。比如“浮世绘”检索到原有的版画卡，两个来源的黏土定格归入同一卡。新纳入的 13 个画风各有稳定 ID、中英文画面描述和独立图像。作品继续使用自己的正向描述或旧值。

所有内置图片在这次验证中原创生成，作为项目资源随桌面与网页交付。共用设定为短发人物穿赭色外套，在车站窗边举起青色杯子。画幅、人物朝向、动作和主体构图尽量保持一致。每个格子独立检查、裁切并离线分发。旧图中的像素风错配，以及都市 3D 和 3D 渲染共用一图，均已替换。生成方法为 ImageGen，同题生成批次 cdb463cb、4eea6783、e5a665e0、de988887，第二轮复核批次 494b4fb6。最后的近邻重做保持人物无首饰、普通外套和车站布景，固定物件之间的差异直接来自画法及材质。

[14 对同题样图](style-neighbors.jpg) 和 [索引](style-neighbors-key.md) 可复查视觉差异。独立评审先观察无标题图片再对照目录。黏土观察厚发束与压痕，皮影观察透光和镂空，古埃及壁画观察侧脸正眼与平涂墙面，四色海报观察网点和套色，赛璐璐观察硬阴影与手绘背景。实拍类分别观察灰阶、光位和饱和彩层。旧胶片与复古港片同题仍可从退色色温、青影和琥珀侧光区分。

## 动态试拍

固定模型 MiniMax H3、同一动作、方形画幅和四秒时长。四条视频分别使用对应内置图作首帧，动作统一为举杯、轻啜、放低并回望窗外。由生成服务实际返回视频，提取约 0.2、1.2、2.2、3.4 秒用于独立读帧。见 [四组运动帧图](style-motion.jpg)，依次为黏土、皮影、复古港片、古典好莱坞彩色。动作期间手塑材料与透光镂空仍可识别，港片的青色窗影和暖侧光也区别于古典棚拍的染印彩层。皮影的运动幅度较小。四条短镜头只覆盖代表性近邻，不能推算其他模型、较长镜头或整部剧的成功率。

## 自定义画风

- 使用真实 Doubao Seed 视觉请求分析皮影预览，最终的正向结果提到暖棕颗粒、镂空剪影、几何色块和扁平叠压，反向建议包括摄影光影、平滑表面和厚涂；该次结果没有把车站、服装或具体人物写入画风。
- 使用 Seedream 5.0 Flash 经工作台同一生图适配器生成皮影候选，显式采用仅正向路径，保存在 [生成结果](custom-generated.png)。原返回图片内容摘要为 `931aa81624b64dfd1e6d0770dd25558b3fc2c4acee09f801f6733e41270d66a7`，此处提供缩小预览。生成后要由作者选择才能替换原示例。
- Chrome 对真实服务使用两部剧。验证别名、空搜索、上传、坏文件、无模型反馈、写入失败重试、取消、切页、重载、旧版本编辑和另一部剧使用。借助可控的延时响应重现编辑中识图结果晚到，保留手填草稿。额外测试验证两项目隔离、库并发版本、ZIP 到空白库中恢复上传的 PNG 原始字节、同名库项和缺图失败回滚。
- 通过本地 HTTP 接收端捕获 Qwen 角色、场景、道具及分镜的真实请求结构，测默认和手选模型、重复反向词合并、900 字镜头截取后保留画风。视频请求通过 Wan 2.6 提交入口建任务，建任务后修改项目，接收端仍收到提交时的正反向内容。这里检验的是工作台发送内容；反向词的视觉效果会随模型、提示词和镜头变化。

## 并行开发的合并演练

工作台产品代码与 `feat/jimeng-quality-chain@9445e30` 在隔离目录中合并，结果保留为本地分支 `codex/style-quality-integration-9445e30`，提交 `2bf537f`。原始 Git 合并在六个文件出现文本冲突。候选中同时保留作者保护的镜头、结构化分镜的编译所有权、幂等视频提交、采用时的画风、图片参考与画风参数，以及两个制作页开关。试跑发现旧集的纯文本提示词会多出默认写实描述，已在工作台源码修正并加入回归用例。候选上 276 项后端、38 项前端测试及 Vite 生产构建通过。对方后续提交需做增量复核。
