# 分镜动作与连续性的通用修复方案

本文是设计与验收方案。目标是让导演写清的一次变化，在分镜生成、润色、视频提示词编译和重试后仍能被拍出来。第 58 号候选提供了一个回归样本。

## 已复现的问题

在工作区分别构造了舞者旋身后停步、水位越过刻线后回落、球撞到挡板后弹回三个输入，每个重复三次。

- 全能分镜的 `withStoryboardAction` 对三个输入都同时保留了正确动作原文和描述错误结果的节拍正文。原文出现在请求中，不能证明节拍忠实。
- 给结构化编译器的字符预算设为比完整提示词少一个字符，三个输入的动作都丢失了逗号后的部分。编译器给出裁剪提示，仍允许提交。这是对预算边界的模拟，不能据此推断某个厂商的日常超限频率。
- 另用雨滴落入池面、帆船调头、舞者退回三个输入，分别走 Seedance、万相、MiniMax H3 和即梦的本地编译配置。原预算下 12 个组合都保留完整动作；预算收紧一个字符后，12 个组合均丢失后半段且未被阻断。这次对照没有调用视频厂商。
- 经典与全能润色均要求反复润色必须明显换词。动作已写准确时，这个要求仍会促使模型重写动词。

## 一份分镜意图，多种模型表达

沿用已有的分镜字段。结构化分镜使用每拍的动作、事件、出镜主体、姿态、持物、机位和转场。旧分镜从动作、结果和用户当前编辑的节拍读取事实。自由文案和无人物空镜也有效。原文没有交代的位置或过程保持未知。

对每个已明确的节拍，保住执行主体、作用对象、动作发生的顺序和结束状态。尤其要区分尝试、完成、中断、撤回和有意维持原状；这些是比较意义的维度，不是匹配动词的词表。空间约束只比较原稿有依据、且该段需要延续的关系。物件随时间变化、画外声音、刻意省略、转场和蒙太奇都可以是合法创作选择。

用户明确改写的分拍机位归该节拍所有。剧本和分镜字段约束剧情事实。旧动作字段里混写的运镜，不能在提交时升级为覆盖所有节拍的命令。发生实质冲突时，应定位到两处有分歧的文本；一次提交只采用一套可执行的安排。

## 接入与失败处理

| 环节 | 行为 | 可检查的结果 |
|---|---|---|
| 初稿和润色 | 从当前来源逐拍对照候选稿。检查明确的动作过程、结果、空间关系和画外信息；允许等义改写，也允许保留准确的原句。取消为了显得“润色过”而强制换词的要求。 | 有实质差异时能指出原稿依据、候选稿片段和所在节拍；有冲突的自动改写不得静默覆盖编辑稿。 |
| 机位与连续性 | 连续动作核对上一拍结尾和下一拍开头。在画面里承担叙事的信息需要可见的机位或其他明确表达方式。硬切可以换机位；是否承接同一动作由故事时间和导演标记决定。 | 有因果影响的状态跳变可被指出。对于有意省略或证据不足，只说明不确定处。 |
| 编译和重试 | 各视频适配器从同一份已确认的节拍取得事实。先精简重复或可选修饰。预算不足以容纳必要动作时，复用现有超长提示并指出相应节拍。旧分镜重新生成时按当前稿处理。 | 生成页、画布、批量和重试提交一致；改变模型或提示词长度预算不能悄悄改变动作结果。 |
| 成片审看 | 将实际切点、画面和对白与已提交的节拍并排核对。区分平台漏传、模型未执行、创作意图尚未明确三种结果。 | 文件规格可由程序判断；语义和表演需要画面证据。只有软时长提示能力的模型，不能承诺帧级切点。 |

格式、引用、时长合计、预算和原稿版本可做确定性检查。自由文字的同义改写与空间可拍性需要语义复核。复核应返回对应原文和理由；对于无法可靠判断的情况，保留作者稿和具体疑点。实际视频仍需另外审看。

## 验收用例

| 变化维度 | 应当通过 | 应当检出 |
|---|---|---|
| 单人动作 | 舞者起身、旋转、停步，用不同措辞表达同一顺序 | 三步润色成“舞者站在帘前” |
| 无人场景 | 水位越线后回落；另一个镜头可以只表现静止水面 | 明确的回落过程被写成“始终不变” |
| 非人主体 | 球触及挡板并弹回，镜头可以固定 | 预算缩短后只剩下落，回弹消失 |
| 意图与结果 | 人物伸手又收回，对象仍在原处 | “尝试”被改成“拿到”，或接收方被对调 |
| 创作例外 | 有意跳时、插入空镜、反打、画外对白或持续静止 | 同一连续动作中凭空换位、换物、换说话人 |

每组至少有等义通过样本和改变事实的失败样本。对同一组再替换角色、道具、画风、画幅和模型，并检查首次生成、重复润色、旧稿重试、刚好达到预算与略微超限。保留未用于编写规则的作品做盲测，分别记录漏检及误拦。单个样片更好看或一次测试通过，均不足以证明整条链路已经修复。
