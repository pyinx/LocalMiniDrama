# 分镜动作与连续性

写初稿或润色时，逐拍对照剧本、分镜动作与结果、作者当前稿。找出是谁或什么发生了变化、作用到谁或什么、先后顺序及结束状态。保留尝试、完成、中断、撤回之间的差别。允许等义改写；原句已经准确可拍时可以原样保留，重复润色也一样。

每一拍按作者为这拍指定的机位表达。先判断观众需要看见或听见什么，再选择构图、表演、声音和切点。如果关键是两人之间的交接，只拍一张脸可能看不见递出和接收；如果关键是听完消息后的等待，一个固定的面部近景可以成立。沿用原稿已建立且仍然相关的方位、持物与视线关系。跨切点延续同一动作时核对上一拍的结束状态。明确的跳时、反打、画外声、空镜和持续静止都可以成立。

例如，“水位越线又回落”可写成“水漫过刻度，随后退到线下”。只写“刻度被淹没”会丢失回落。人物伸手后收回，道具仍在原处；改成已经拿到道具会改变结果。只在原稿交代过的维度上判断，不为空镜添人，也不为满足变化数量编造动作。

对照后先修正候选稿中能由来源确定的偏差。若相互矛盾的来源需要作者取舍，指出具体节拍、来源原句、与之冲突的句子和各自意味着什么，保留待确认稿。提交给视频模型的每拍只写一套动作和机位。
