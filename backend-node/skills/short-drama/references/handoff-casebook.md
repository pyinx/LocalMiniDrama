# 交接穿帮案例（结构化分镜）

多段连播时，每一段单独生成，段与段、镜头与镜头之间靠文字交接。下面三类穿帮最常见，整集检查会以警告提示：`holding_changed`、`character_vanished` / `character_appeared`、`facing_flipped`。警告只提醒，不拦生成；确实是有意的变化，在动作里写明即可。

## 一、持物守恒（`holding_changed`）

**症状**　上一镜 `holding` 是「纸箱」，下一镜变成空手，或手里多出上一镜没有的东西，画面里物品突然消失或出现。

**根因**　每一镜的 `subjects[].holding` 是各写各的，没有人维护「这个人手里现在有什么」。

**改写**
- 物品易手，就在动作里写出过程：写「把纸箱放在桌上」「接过解除协议」，并让物品名与 `holding` 里的叫法一致（写「纸箱」就不要在动作里写「箱子」，否则检查认不出）。
- 物品一直在手上，下一镜的 `holding` 照抄上一镜，别漏写。
- 腾手必先放物：要用手做别的事，先写放下，再写新动作。
- 多件物品用顿号分隔，顺序不影响判断。

## 二、离场与入场（`character_vanished`、`character_appeared`）

**症状**　上一段末镜两个人，下一段只剩一个，另一个人没有走出画面；或下一段首镜多出一个人，上一段没有他。远景里人数悄悄变化。

**根因**　下一段的 `cast` 是按本段剧情单独列的，没有回看上一段末镜谁在场。

**改写**
- 角色要走：在上一段末镜的 `action` 里写「某某走出」「某某离开」「某某出画」，让离场完整可见。
- 角色新来：在下一段首镜的 `action` 里写「某某走进」「某某进来」「某某入画」。
- 人物其实还在，只是不再入镜：下一段 `cast` 里保留他，并在首镜给出位置或画外声，不要让他凭空蒸发。
- 路人、群演标记 `group: true`，不参与这项检查。

## 三、朝向左右翻转（`facing_flipped`）

**症状**　同一场戏，上一段末镜人物 `facing` 是「身体侧向画左」，下一段首镜变成「身体侧向画右」，观众感觉人物瞬移或镜头越过了轴线。

**根因**　各段独立选朝向，没有承接上一段落幅。

**改写**
- 同场景连续的两段，首镜 `facing` 沿用上一段末镜的左右。
- 确实要换边：在首镜 `action` 里写「转身」「转向」「绕到」「走到」，让换边是看得见的动作。
- 「正对镜头」与「背向镜头」之间的变化不算翻转，不会被提示。

## 检查范围

动作里的交代要写出角色名（「林远走出」，不要只写「他走出」），检查靠名字和动词出现在同一镜头的动作里来认。两个以上的人物同时左右互换，视为反打换了机位，不提示。

只比较 `holding`、`cast`、`facing`，且只在分镜序号连续、同一场景的相邻两段之间，以及同一段内相邻镜头之间。景别、位置、视线、运动方向不在检查内，写稿时仍要自己承接。动作里没有提到的物品去向，检查认为没交代。
