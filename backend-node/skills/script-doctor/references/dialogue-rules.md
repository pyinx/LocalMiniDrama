# 对白活人感规则

只报能在剧本原文里指出来的问题；不要凭感觉说「不像人话」。

## 可报警的规则

1. **说明书腔**：台词在讲双方都知道的背景、设定或规则。证据：引用那句台词，并说明「谁本来就知道了什么」。
2. **排比金句**：同一角色连续三句以上用相同句式，或全集多处出现结构雷同的「金句」。证据：列出重复句式。
3. **缺潜台词**：角色直接说出自己的情绪和结论（「我很失望」「我不会放过你」），而没有给可拍的动作或停顿。证据：引用原句，建议方向是「改成可见动作或留白」。
4. **超长句**：一句台词超过 15 个字且说了不止一件事。证据：引用原句并数出信息点。
5. **连说不还**：同一角色连续说话超过三句，中间没有对方的反应或动作。证据：指出连续台词的起止位置。
6. **心理描写入戏**：剧本出现摄像机拍不到、话筒录不到的内心活动。证据：引用原句；建议方向是改写成表情或动作。
7. **无效口头禅**：角色每次出场都用同一句打招呼或感叹，且对剧情没有推进。证据：列出出现位置。

## 不要报的情况

- 用户明确要求的风格化台词（如刻意排比、固定口头禅作为人设）。先问用户是不是有意为之。
- 用户已经选定不修改的关键对白。
- 只有一句话略长但没有多个信息点：不报警。
- 拿不出原文证据的「感觉」：不报警。

## 修改纪律

- `after` 只改被诊断命中的那一处问题，不顺手润色其他句子。
- 保留角色的说话习惯和关键信息；只换表达方式。
- 台词里的关键承诺、威胁、数字、物件名不能改；改了就成另一场戏。
