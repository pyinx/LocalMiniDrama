# 深审 mode 的判断重点

这些是给模型注入的提示方向，也是你复核 finding 是否靠谱的清单。只报你能引用剧本原文作证据的问题。

## selection：题材与赛道判断

- 一句话能不能说清「谁、什么处境、要什么、谁拦着」。
- 核心冲突是否可拍：有没有具体对手、具体障碍、具体代价。
- 有没有把题材标签（如「逆袭」「甜宠」）当成故事本身。
- 只报定位问题，不评价台词细节。

## first-three：前三集生死线

- 第 1 集前两三句有没有可见的冲突或异常；没有就是开场不够快。
- 每集结尾是否停在最紧的那一刻，用画面或台词露出悬念。
- 三集之间的冲突是否升级：对手、手段、代价有没有变化；同一个套路重复三次以上算同质化。
- 交代背景时有没有让角色互讲双方早知道的事。

## dialogue：对白活人感

- 说明书腔：角色在讲设定、讲背景、讲观众已知的事。
- 排比金句：连续多句结构相同、像念稿子。
- 缺潜台词：角色把情绪和结论都说出来，没有留白给表情和动作。
- 每句是否只说一件事；同一个人连说超过三句是否没有插入对方反应。
- 具体规则见 `dialogue-rules.md`。

## full：综合深审

依次覆盖前三集的开场与钩子、冲突与反转、对白质感、人物动机、可拍性；最多报 8 条，按 `blocking` → `warn` → `info` 排列。同一问题不要拆成多条。
